# MIPintegra

Protótipo da plataforma de consulta da compatibilidade entre controle químico e biológico, produto do projeto de pesquisa "Repensando a seletividade de inseticidas: desenvolvimento de um modelo de compatibilidade entre controle químico e biológico" (Emile Dayara Rabelo Santana, UFRGS, Edital nº 09/2026).

Site estático: `index.html` + `logo.png`. Abre direto no navegador, também sem internet.

Os resultados exibidos são hipotéticos e servem para demonstrar o modelo; os experimentos ainda serão conduzidos.
